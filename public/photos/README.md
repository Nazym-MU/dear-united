# Photos

Drop images here and they appear in the story's polaroid frames automatically.
Expected filenames (defined in `src/data/story.js` — edit them there freely):

- `ground-1.jpg`, `ground-2.jpg` — chapter 01, The Ground
- `east-1.jpg`, `east-2.jpg` — chapter 02, East Stand
- `stretford-1.jpg`, `stretford-2.jpg` — chapter 03, Stretford End
- `saf-1.jpg`, `saf-2.jpg` — chapter 04, Sir Alex Ferguson Stand
- `bobby-1.jpg`, `bobby-2.jpg` — chapter 05, Sir Bobby Charlton Stand
- `pitch-1.jpg`, `pitch-2.jpg` — chapter 06, The Pitch

Landscape (4:3-ish) crops look best. Until a file exists, the frame shows a
quiet "photo to come" placeholder.
